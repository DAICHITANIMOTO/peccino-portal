01

まず最初に：ホーム画面に追加

毎回URLを打たなくても、ホーム画面のアイコンから一発で開けるようになります。初回に案内が出ますが、消してしまった場合は手動でも追加できます。

iPhone / Safari
  1. 画面下の共有ボタン（□に↑）をタップ
  2. メニューを下にスクロールして「ホーム画面に追加」を選択
  3. 右上の「追加」をタップ

Android / Chrome

  1. 右上の「⋮」メニューをタップ
  2. 「ホーム画面に追加」（または「アプリをインストール」）を選択
LINEやInstagramのリンクから開いた人へ： そのままだと追加できません。右上「…」→「Safari（またはブラウザ）で開く」を選んでから、上の手順をどうぞ。
02

ホーム

開いて最初に出る画面。今シーズンのざっくりした状況が一目で分かります。

ここで見られること

  • 今季の勝敗（真ん中の円グラフ）
  • 打者・投手リーダーボード — 打率・本塁打・打点・防御率などのトップ選手。横スクロールで他の指標も
  • 直近の試合結果 — タップで試合詳細へ
  • 「あなたは誰?」で自分の名前を選ぶと、次回からホームに自分のページへのショートカットが出ます
画面下の5つのタブ（ホーム / ランキング / 選手 / 試合 / 入力）で各ページに移動します。
03

ランキング

指標ごとの順位表。誰が一番打っているか、防御率が良いかがすぐ分かります。

ここで見られること

  • 打者 / 投手 の切り替え
  • 年度（全期間 / 2026年 / 2025年 / 2024年）の切り替え
  • 並べ替える指標 の選択 — 打率・本塁打・打点・盗塁・OPS、選球眼(IsoD)・長打力(IsoP) など
  • 基本6指標は常に表示。表を横スクロールすると残りの指標も見えます
最低出場条件（打者は打数5以上／投手は投球回1以上）を満たした選手だけが載ります。
04

選手

選手一覧から名前をタップすると、その選手の詳細ページに入ります。

選手一覧

  • 全メンバーの背番号・ポジション・主要成績
  • 名前をタップ → 個人ページへ
  • ページ上部から表彰・タイトル一覧にも行けます

個人ページで見られること

  • プロフィール・PR文・受賞歴
  • 通算成績（打率・OPS・防御率など、期間で切替）
  • セイバー指標（IsoP / IsoD / RC27 / WHIP / FIP など）
  • 直近5試合の調子、対戦相手別成績、月別推移グラフ、勝ち試合／負け試合での違い
  • 2026年は打球方向スプレーチャート・打球タイプ・守備成績も
  • 通算の節目（20安打・二桁盗塁など）を達成すると🎉バッジが付きます
05

試合

全試合の結果。リスト表示とカレンダー表示を切り替えられます。

リスト表示

  • 年度／公式・練習／勝敗／対戦相手で絞り込み
  • 試合をタップ → スコアボード＋出場選手の成績（ボックススコア）

カレンダー表示

  • 試合のあった日が勝敗の色で表示（緑＝勝ち／赤＝負け）
  • 日付をタップ → その日の試合へ。ダブルヘッダーの日は複数出ます
06

表彰・タイトル

選手プロフィールの受賞歴を年度ごとにまとめたページ。選手一覧の上部からリンクしています。

ここで見られること

  • 年度別のMVP・最多本塁打・最多打点・記録員賞 などの受賞者一覧
07

補足

  • ダーク／ライトは端末の設定に自動で合わせます
  • データは自動で更新されます。記録担当が試合後に送信すると、数分でこのページに反映されます
  • 一番下のタブの「入力」は記録担当専用です（合言葉が必要）。他の人は開かなくて大丈夫です
  • 数字がおかしい・載っていない試合がある等あれば、記録担当か運営に連絡してください
